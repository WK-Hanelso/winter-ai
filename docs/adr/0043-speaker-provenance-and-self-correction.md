# ADR 0043 — 실제 발화자 구분과 자기 정정 검사

상태: Text-first의 제한된 대화 수정에 적용. 품질 전체 수락은 별도다.

## 근거와 결정

저장된 원문과 역할이 모델 입력에도 있었지만, 모델이 자신의 이전 발언을 부정하는
실패를 확인했다. 별개로 사실을 바로잡는 답변 뒤의 내용 없는 자기 정정을 기억 주장으로
분류해, 근거 있는 응답 전체를 기억 부재 안내로 바꾸는 검사 오탐도 재현했다.

1. `companion`의 가상 예시 종료 경계를 발화자/근거 구분 계약으로 바꾼다. 원문·역할·
   순서와 Identity를 유지한다. 별도 분류 LLM, 요약, DB migration, 자동 기억 승인 없이
   동일 모델이 사용자 진술과 자신의 농담/추측을 구분하도록 한다.
2. 기억 검사는 원문 claim unit 전체가 내용 없는 자기 정정인 경우에만 긍정적 기억
   주장으로 분류하지 않는다. 따옴표를 제거한 문자열에는 이 예외를 적용하지 않는다.
   같은 단위에 사실/인용이 포함되거나 다음 단위에 별도 사실/저장 약속이 나오면 정상
   근거 검사를 유지한다. 다른 주장 종류의 검사도 건너뛰지 않는다.

## 대안과 한계

추가 지침, 실제 기록의 JSON 치환, 가상 예시 제거를 로컬에서 비교했다. 목표 실패를
안정적으로 해소하지 못하거나 다른 답변을 악화시킨 대안은 배포하지 않았다. 현재 수정은
명시적 발화자 질문과 자기 정정 오탐을 다루며, 생략된 질문의 의미 해석이나 자연스러운
감정 교류 전체를 해결하지 않는다. 자기 정정 문법 판별은 제한적이며 일반 한국어 의미
분석기나 허위 기억 검증의 완전한 대체물이 아니다. 실패 기록은 로컬에서 보존한다.

검증: `test_memory_self_correction.py`, `test_speaker_context_boundary.py`, 기존 claim/
grounding/정정/문맥 보존 회귀. 실제 대화와 설계 비교 원출력은 Git에 올리지 않는다.
