# ADR-0004: 무엇을 학습시키고 무엇을 학습시키지 않는가

- Status: Accepted
- Date: 2026-08-10
- Issues: [#103](https://github.com/WK-Hanelso/winter-ai/issues/103),
  [#96](https://github.com/WK-Hanelso/winter-ai/issues/96),
  [#98](https://github.com/WK-Hanelso/winter-ai/issues/98),
  [#94](https://github.com/WK-Hanelso/winter-ai/issues/94)
- Supersedes: 없음. [ADR-0002](0002-coupled-human-reference-baseline.md) 결정 5의 실행이다

## Context

`ADR-0002` 결정 5는 이렇게 정했다.

> 먼저 prompt/few-shot baseline을 held-out scene에서 평가한다. 관찰된 실패에 따라
> Qwen LoRA/SFT, appraisal model, TTS adaptation을 **각각** 결정한다.

그 평가가 끝났다. 이 ADR은 그 결과로 component별 결정을 내린다.

### 측정된 사실

| 항목 | 결과 | 출처 |
| --- | --- | --- |
| 말투 스타일 거리 (prompt) | 0.252 | #96 |
| 말투 스타일 거리 (이전 정책) | 0.619 | #96 |
| 바닥값 (Reference의 자기 거리) | 0.162 | #96 |
| 남은 격차 중 범주 분포(존댓말 비율)의 몫 | 0.102 / 0.252 | #96 |
| 존댓말 비율 지시 이행 | **3회 모두 0.0** (지시: "가끔 섞어") | #96 |
| 발화 길이·필러율 | 목표치를 주면 따름 (1.0 → 0.25) | #96 |
| 대화 쌍 생성 | 5분에 11쌍 | #98 |
| 확장 시 규모 (추정) | 10시간에서 약 1,300쌍 | #98 |
| 대화 내용 적절성 | **측정하지 않음** | — |
| 목소리 | 프롬프트로 불가능 | — |

### 아직 측정하지 않은 것

- **대화 내용의 적절성.** 지금까지의 평가는 말투 *분포*만 본다. "이 질문에 이렇게
  답하는 것이 맞는가"는 재지 않았다
- 다른 register(1:1 대화)에서의 말투. 측정은 방송 register에서만 이뤄졌다
- 화자 분리·쌍 생성의 다른 구간·source 재현성

## Decision

### D1. 말투 — 아직 학습하지 않는다. 범주 선택을 모델 밖으로 뺀다

측정이 가리키는 실패는 하나다. 모델은 **범주 선택을 규칙으로 다루지 비율로 다루지
않는다.** "주로 반말을 쓰되 가끔 존댓말도 섞어"라고 지시해도 존댓말이 한 번도 나오지
않는다.

이는 모델 능력의 부족이라기보다 **지시로 분포를 만들려 한 설계의 문제**다. 분포가
필요하면 분포를 만드는 쪽이 정하면 된다.

`VerbalStylePlanner`는 이미 turn마다 지시문을 고른다. 여기서 **register도 turn마다
고르게** 한다. 측정된 비율(존댓말 약 0.26)에 따라 이번 turn의 register를 정하고,
그 turn에는 절대 규칙으로 지시한다. 모델이 잘 따르는 형태(절대 규칙)로 주면서
전체로는 측정된 분포가 된다.

이 변경으로 남은 격차 0.252 중 0.102가 사라지면 총 거리는 약 0.15로 **바닥값 0.162
아래**가 된다. 그러면 말투에 학습이 필요하다고 말할 근거가 없다.

**재검토 조건**: turn 단위 register 선택을 적용하고 #96의 harness로 다시 측정했을 때
거리가 바닥값 근처로 내려가지 않으면, 그때 말투 학습을 다시 검토한다.

### D2. 대화 행동 — 아직 학습하지 않는다. 먼저 측정한다

**대화 내용의 적절성을 한 번도 측정하지 않았다.** 측정 없이 학습을 결정하는 것은
`ADR-0002` 결정 5가 금지한 바로 그 일이다.

#98로 (질문 → 답) 쌍을 만들 수 있게 됐으므로 이제 측정할 수 있다. 쌍의 일부를
held-out으로 남기고, 같은 질문에 companion이 낸 답을 실제 Reference의 답과 비교한다.

**재검토 조건**: 그 측정에서 prompt/few-shot이 실패하면 학습을 검토한다. 그때
데이터 규모(D4)가 함께 문제가 된다.

### D3. 목소리 — 학습이 필요하다. 대안이 없다

프롬프트로 음색을 만들 수 없다. TTS adaptation은 처음부터 학습 문제이며 이 결정에
측정이 필요하지 않다.

다만 **지금 착수하지 않는다.** roadmap Order 7(Reference Voice baseline)이 선행이며,
현재 Voice adapter도 구현돼 있지 않다. 이 ADR은 "목소리는 학습 대상"이라는 것만
확정하고 착수 시점은 Order 7 이후로 둔다.

### D4. 데이터 확장 — D1·D2의 결과에 걸어 둔다

10시간 확장(H8)은 수집·전사·화자분리 비용이 든다. **지금 결정하지 않는다.**

- D1이 성공하면 말투에 추가 데이터가 필요 없다
- D2 측정이 성공하면 대화 행동에도 필요 없다
- 둘 중 하나라도 실패하면 그때 필요한 양을 역산해 확장한다

현재 추정으로 10시간에서 약 1,300쌍이 나온다. **이는 SFT에 넉넉한 양이 아니다.**
학습이 필요하다는 결론이 나면 데이터 확보가 그 자체로 별도 과제가 된다는 뜻이며,
확장 결정을 미루는 것은 그 과제를 불필요하게 시작하지 않기 위해서다.

### D5. grounding은 학습 대상이 아니다

지어내기 억제(#94)는 프롬프트로 줄었지만 보장은 아니다. 그러나 이는 학습으로 풀
문제가 아니라 **출력 검증으로 풀 문제**다. 보장이 필요해지면 생성 후 검사를 넣는다.

## Consequences

- 지금 시점에 학습에 착수하는 component는 **없다**
- 다음 두 작업이 결정의 선행 조건이 된다
  1. turn 단위 register 선택과 재측정 (D1)
  2. 대화 내용 held-out 평가 설계와 측정 (D2)
- 두 작업 모두 이미 있는 harness를 확장하는 일이며 새 모델을 필요로 하지 않는다
- 목소리는 학습 대상으로 확정됐으나 Order 7 이후로 미뤄진다

## Rejected alternatives

### 지금 LoRA/SFT를 시작한다

측정이 가리키는 실패가 **범주 분포 하나**이고, 그것은 모델 밖에서 고칠 수 있다.
고칠 수 있는 것을 고치지 않고 학습으로 덮으면 무엇이 효과를 냈는지 알 수 없게 된다.
대화 행동은 애초에 측정이 없어 학습 여부를 판단할 근거가 없다.

### 데이터를 10시간으로 먼저 확장한다

필요한 양을 모르는 상태에서 수집하는 것이다. 확장은 되돌리기 어렵고(승인·저장·전사
비용), 지금 추정치 1,300쌍이 충분한지조차 판정 기준이 없다.

### 말투를 few-shot 예시로 해결한다

Reference의 실제 발화를 프롬프트에 넣는 방법이다. 배제하지 않았으나 D1보다 뒤에 둔다.
few-shot은 개인정보를 프롬프트에 상시 노출시키고, register 분포 문제를 직접 겨냥하지도
않는다. D1이 실패하면 그때 검토한다.

## 이 ADR이 바꾸지 않는 것

`ADR-0002` 결정 6은 그대로다. **Human Reference는 최종 겨울이가 아니다.** 이 ADR의
모든 결정은 Reference 재현을 기준으로 하며, Winter Delta는 별도 Milestone이다.
