# ADR 0038 — Core 보완 뒤에도 실제 대화 품질 승격 보류

- 날짜: 2026-09-11
- 상태: #136 평가 판정 채택
- 근거: [28턴 실제 결과](../evaluations/136-text-reevaluation/README.md)

## 관찰

#134 응답 보존과 #135 검사 변경 뒤 같은 A.X로 7장면 × 2턴 × 2정책을 실행했다.
명시적 저장 기억은 회상했지만, 모르는 기억에 대한 초안과 repair 모두 실패했다.
설명 지침을 따라 나온 원문을 claim/style 검사기가 훼손한 경우도 있었다.
새 repair 지침은 질문 주체 보존을 실제로 보장하지 못했다. 코드 회귀 통과와 별개다.

## 결정

- legacy 기본값 유지, contextual 승격 보류. 어느 쪽도 원하는 관계적 대화 품질 승인 아님.
- 원 초안/repair/최종·claim 검사를 별도 보존하고 #132/#135의 기록을 고쳐 쓰지 않는다.
- 실행한 28턴의 범위만 완료한다. 모델 교체·새 규칙·개인 DB·서비스 변경은 하지 않는다.
- 다음 #137은 같은 모델의 최소 지침과 전체 Core 문맥을 대조한다. 출력 전 검사를 거치지
  않은 원문은 진단 자료일 뿐 운영 답변이 아니다. 문맥/모델/후행 검사 원인을 분리하고
  다음 실제 변경을 결정한다. 상용 API나 모델 weight 다운로드는 해당 범위가 아니다.

## 한계

합성 Identity·작은 개발 회귀 장면·단일 seed·한 배치다. 두 정책의 multi-turn 문맥은 첫
응답부터 달라서 인과적인 순위를 내릴 수 없다. 독립 blind 평가/사용자 관찰/장기 기억 및
Voice는 미검증이다. 모델 metadata는 같지만 weight digest는 제공되지 않았다.
TTFT는 측정하지 않았다. 임시 연결은 닫았고 상시 CLI 연결을 복구하지 않았다.
