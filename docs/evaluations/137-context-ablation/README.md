## 판단과 다음 단계

1. 최소 지침에서도 기억/판단 실패가 남았다. 현재 모델+예산+최소 지침 조합의 한계 근거이며
   Core 간섭만으로 모든 실패를 설명할 수 없다. 모델이 어떤 prompt에서도 불가능하다는 뜻은 아니다.
2. 전체 지침이 짧고 직접적인 답에 도움을 준 장면도 있다. 지침 전체 제거를 해법으로 채택하지 않는다.
3. 검사 오탐은 독립적인 문제다. 정상 원문을 훼손할 수 있지만 이번에는 audit만 했으므로
   새 repair의 최종 사용자 응답 품질을 검증한 것은 아니다.
4. 다음은 **T2.7 공개 관계형 대화 모델·예시 자료 조사**다. 모르는 기억, 자기 관점,
   상담형 상투성, 정확한 문맥 유지에 대한 근거와 장비/라이선스를 소수 후보별로 정리한다.
   새 regex/모델 다운로드/운영 교체를 이번 Issue 안에서 수행하지 않는다.

개인 데이터와 운영 DB, src 정책/gate, Voice, 상시 서비스를 변경하지 않았다. 코드/config/실험은
read-only, 결과 폴더만 쓰기 허용, 임시 DB는 tmpfs였다. Host 임시 18082 SSH 터널은 종료했다.
운영 기본 18080 복구나 CLI 사용자 실측은 하지 않았다. Text-first maturity는 contract 유지다.

## 재현

Docker dev에서 개인 data/identity/model/credential을 mount하지 않고 src/configs/experiments만
read-only로 제공한다. Orin으로 향하는 일시적 loopback 연결과 별도 결과 폴더가 필요하다.

```bash
python experiments/text_context_ablation.py --url http://127.0.0.1:18082 --output /results/trace.jsonl
```

결과 파일은 exclusive 생성으로 덮어쓰지 않는다. 위 연결은 이미 종료됐으므로 지금 사용자에게
실행을 요구하지 않는다. 원본은 비공개 로컬에 있어 다른 clone에서는 이 요약만으로 raw를
재검토할 수 없다. 재현 코드/사전 계약/검사와 로컬 digest를 함께 보존한다.
