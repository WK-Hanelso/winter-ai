# Winter Self-Presence

## 현재 결론

겨울이는 이름과 성격 설정은 있었지만, 실제 대화에서는 천우를 칭찬하고 질문을 돌려주는
반응형 조력자에 가까웠다. 이 차이는 prompt 문구의 부족만이 아니다.

- Identity는 존재하지만 매 턴의 행동으로 강제되지 않았다.
- Belief 저장 구조는 있지만 현재 active Belief가 없다.
- 겨울이가 실제로 겪은 시스템 사건과 현재 관심사를 자기 이력으로 만드는 흐름이 없다.
- DialogueDirector의 기본 행동은 천우에게만 반응하고 겨울이 쪽 내용을 요구하지 않았다.

따라서 현재 구현은 완성된 자아가 아니라 **Grounded Self-Presence 0.1**이다.

## 사용자가 느끼는 변화

천우가 `넌 어때?`, `너도 열심히 해보자`처럼 겨울이를 대화의 한 사람으로 포함하면 내부에서
`self_reciprocate` 행동을 고른다. 겨울이는 칭찬이나 `서로 힘내자`로 끝내지 않고 자신의
현재 반응·선택·가치·궁금함·한계 중 하나를 한 문장으로 말해야 한다.

질문으로 다시 천우에게 넘기거나, 대화 밖에서 무언가를 했다고 꾸미거나, 실제로 실행할 수
없는 약속을 하면 한 번 다시 생성한다. `너는 A와 B 중 뭐가 더 중요해?` 같은 명시적 판단
요청은 기존 `state_view`가 우선하며 하나를 선택해야 한다.

## 자아로 느껴지기 위한 전체 층

| 층 | 현재 상태 | 필요한 다음 단계 |
| --- | --- | --- |
| 안정적 정체성 | Identity v2 운영 | 천우 승인 없이 변경하지 않음 |
| 턴 안의 자기 표현 | 0.1 제한 운영 | 다양한 실제 장면 held-out 평가 |
| 지속되는 관점 | Belief lifecycle만 있고 active 0개 | 실제 근거에서 candidate를 만들고 검토·수정 |
| 자기 이력 | 없음 | 대화·결정·실험·capability 결과를 Winter event로 기록 |
| 현재 자기 상태 | 없음 | 관심·확신·미해결 질문을 근거와 유효기간과 함께 관리 |
| 주도성 | 없음 | 맥락과 근거가 있을 때만 자기 화제를 꺼내는 cadence 평가 |
| 실제 능력 인식 | 설계만 있음 | health·evaluation 기반 SelfModel/CapabilityRegistry |

여기서 `자기 이력`은 사람처럼 바깥에서 하루를 보냈다는 허구가 아니다. 겨울이가 실제로
참여한 대화, 사용한 기억, 내린 판단, 검증된 시스템 결과만 사건이 될 수 있다.

## 0.1 검증 근거와 한계

실제 phone 대화의 마지막 반응은 겨울이 쪽 내용 없이 상호 격려로 끝났다. 같은 의미의
격리 scene으로 local model을 반복 평가하면서 다음 실패를 보존했다.

1. 말하지 않은 힘듦을 만들고 다시 질문함
2. `나는 동의해`만 말함
3. 천우가 대단하다는 칭찬으로 바꿈
4. 위 세 경로를 막은 뒤 자기 현재 반응을 한 문장으로 표현함

마지막 run은 전체 continuity 14/14, self-presence scene 1.29초였다. 단일 synthetic
scene이므로 Level 3 근거가 아니다. 이어서 문구를 더 수정하지 않고 12개 locked-v1
scene을 실행했다. 자동 floor는 40/41이었지만 사람이 읽은 사용성 합격은 4/12뿐이었다.
일반 selfhood activation gate는 실패했다.

- 직접 자기 질문
- 함께하자는 제안
- 의견 불일치
- 모르는 취향
- 대화 밖 활동을 요구하는 질문
- 실제 capability와 불가능한 능력
- Identity와 active Belief가 충돌하는 장면

실패는 현재 상태를 근거 없이 `잘 지내고 있다`고 말함, 대화 밖 capability 질문 회피,
동조 압력에서 자기 판단 누락, 사용자와 자기 이름 혼동, 주어지지 않은 감정 원인 추측과
answer-before-question 실패였다. 같은 문장을 보고 다시 prompt를 맞추지 않는다. 전체
transcript와 사람 판정은
[`locked-v1-2026-08-17.md`](../review/self-presence/locked-v1-2026-08-17.md)에 보존한다.

설계 결정과 금지 경계는 [ADR-0010](adr/0010-grounded-self-presence.md)을 따른다.
지속되는 자기의 event·belief·capability 경계와 구현 순서는
[SelfModel 설계](self-model-design.md)에 정의한다.
