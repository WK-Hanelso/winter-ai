# 말투 held-out 평가

말투 profile이 실제로 Reference를 닮았는지 숫자로 재는 절차와 결과다.
`ADR-0002` 결정 5가 요구한 held-out 평가에 해당하며, Order 10 학습 방식 결정의
입력이다.

관련: [verbal-style-profiles.md](verbal-style-profiles.md),
[reference-speech-style.md](reference-speech-style.md).

---

## 1. 무엇을 잴 수 있고 무엇은 못 재는가

**잰다**: 생성된 말의 **분포**가 Reference와 얼마나 가까운가. 존댓말 비율, 발화 길이,
필러율, 종결 어미 구성.

**못 잰다**: 내용이 맞는가. 독백 source에는 (입력 → 응답) 쌍이 없어 "이 상황에서
이렇게 반응하는 것이 맞다"를 평가할 수 없다. 화자 분리 이후의 일이다.

**스타일 거리가 작다고 "말투를 재현했다"고 말하지 않는다.** 분포가 닮았다는 뜻일 뿐이다.

## 2. 두 개의 기준선

측정값 하나만으로는 좋은지 나쁜지 알 수 없다. 두 기준선을 함께 낸다.

### 오염 확인

profile은 전사 **전체**에서 도출됐으므로 같은 구간으로 평가하면 자기 답안을 채점하는
것과 같다. 앞 70%에서만 특성을 다시 도출해 전체 도출값과 비교한다.

**결과: 거리 0.0434.** 무시할 수준이며 배포된 profile을 그대로 써도 된다.

### 자기 거리 — 바닥값

같은 사람도 35분 방송 안에서 말투가 변한다. train 구간과 held-out 구간의 거리가
**0.1617**이다.

**생성된 말투가 이보다 가까워지는 것은 의미가 없다.** 사람 자신도 그만큼 떨어져 있다.

## 3. 결과 (source-004, 3회 반복)

probe 질문 10개를 두 profile로 각각 답하게 하고, 생성된 말의 분포를 held-out
구간과 비교했다.

| profile | 1회 | 2회 | 3회 | 평균 |
| --- | ---: | ---: | ---: | ---: |
| `base` | 0.598 | 0.609 | 0.650 | **0.619** |
| `reference_broadcast` | 0.246 | 0.276 | 0.235 | **0.252** |
| 바닥값 (자기 거리) | | | | 0.162 |

Reference profile이 기존 정책의 **약 40% 거리**까지 좁혔다. 반복 간 편차는 ±0.02
수준이므로 차이는 잡음이 아니다.

### 항목별 (수정 후 1회 기준)

| 항목 | 생성 | Reference held-out | 거리 | 가중치 |
| --- | ---: | ---: | ---: | ---: |
| 존댓말 비율 | **0.000** | 0.255 | **0.255** | 0.4 |
| 발화 길이 (단어) | 3.09 | 2.48 | 0.248 | 0.3 |
| 필러 / 100단어 | 2.94 | 2.41 | 0.221 | 0.2 |
| 종결 어미 구성 | — | — | 0.255 | 0.1 |

## 4. 중간에 고친 것 — 측정값을 잘못 옮겼다

첫 측정에서 `reference_broadcast`가 0.583이었다. 원인은 모델이 아니라 profile이었다.

| 항목 | 첫 profile | 결과 | 측정값 |
| --- | --- | ---: | ---: |
| register | `반말만 써. 존댓말 쓰지 마.` | 존댓말 0.0 | 0.31이 존댓말 |
| 길이 | `2문장 이내` | 4.59 단어 | 2.48 |
| 필러 | `가끔 섞여도 괜찮아` | 7.69 / 100 | 2.41 |

**"존댓말 비율 0.31"을 읽고 "반말만 써"라고 옮긴 것이 잘못이다.** 측정은 분포였는데
지시는 절대 규칙이었다. 필러도 "가끔"이라는 모호한 표현이 3배 과잉으로 이어졌다.

목표치를 명시하도록 고쳤다: `mostly_plain` register, 문장당 단어 상한, 필러는
"아주 드물게".

**결과: 0.583 → 0.252.**

## 5. 가장 중요한 발견 — 무엇이 프롬프트로 안 되는가

수정 후 항목별로 갈렸다.

| 유형 | 항목 | 프롬프트 대응 |
| --- | --- | --- |
| 연속값 | 발화 길이, 필러율 | **잘 따른다.** 1.0 → 0.25 수준으로 개선 |
| 범주 분포 | 존댓말/반말 비율 | **전혀 안 따른다.** 3회 모두 정확히 0.0 |

`주로 반말을 쓰되 가끔 존댓말도 섞어`라고 지시했지만 모델은 **3회 모두 존댓말을 한
번도 쓰지 않았다.** 잡음이 아니라 구조적이다.

**모델은 범주 선택을 규칙으로 다루지 비율로 다루지 않는다.** 연속적인 목표치는
근사하지만, "넷 중 하나는 존댓말"과 같은 분포는 프롬프트로 유도되지 않는다.

### 남은 거리의 대부분이 이것이다

현재 거리 0.252 중 존댓말 항목이 **0.102**(가중치 0.4 × 거리 0.255)를 차지한다.
이 항목이 해결되면 총 거리는 약 0.15로, **바닥값 0.162 아래**가 된다.

즉 **프롬프트 조정으로 나머지는 이미 사람의 자기 편차 수준까지 좁혔고, 남은 것은
범주 분포 하나다.** Order 10에서 학습이 필요한지 판단할 때의 핵심 근거다.

## 6. 실행

```bash
# 모델 없이 오염 확인만
PYTHONPATH=src:. python3 experiments/style_holdout_eval.py \
  --transcript <외장>/derived/audio/stt-pilot/<source>-0-<duration>.vtt \
  --skip-generation

# 전체 (로컬 LLM 필요)
docker compose -f compose.yaml -f compose.llm.yaml -f compose.gpu.yaml run --rm \
  -v "$REFERENCE_STORAGE_ROOT:/reference-data" dev \
  python experiments/style_holdout_eval.py \
  --transcript /reference-data/derived/audio/stt-pilot/<source>-0-<duration>.vtt
```

## 7. 알려진 한계

- **분포만 잰다.** 내용의 적절성은 평가하지 않는다
- probe 질문 10개, source 1개, 모델 1개, 3회 반복이다. 통계적 검정을 하지 않았다
- 가중치(register 0.4 등)는 설계 판단이며 측정으로 도출한 값이 아니다. 가중치를
  바꾸면 순위가 바뀔 수 있다
- 종결 어미 분류의 미분류 비율이 높아(약 67%) 존댓말 비율은 분류된 것에 대한 값이다
- 바닥값은 source 한 개의 전반부·후반부 차이다. 다른 방송 사이의 차이는 더 클 수 있다
- 프롬프트를 지표에 맞춰 조정하면 지표에만 최적화될 위험이 있다. 이번 수정은
  지표가 아니라 **측정값**에 맞춘 것이지만, 반복하면 경계가 흐려진다
