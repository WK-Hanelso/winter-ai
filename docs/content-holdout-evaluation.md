# 대화 내용 held-out 평가

말투가 아니라 **무슨 말을 하는가**를 재는 절차와 첫 결과다.
`ADR-0004` D2가 대화 행동 학습 결정의 선행 조건으로 건 측정이다.

관련: [style-holdout-evaluation.md](style-holdout-evaluation.md),
[diarization.md](diarization.md).

---

## 1. 이 측정이 답하는 것과 답하지 않는 것

**답한다**: companion의 답이 Reference가 실제로 한 답과 얼마나 가까운가.

**답하지 않는다**: 그 답이 좋은가. 기록된 답은 질문마다 하나뿐이고 다른 답도 똑같이
적절할 수 있다. **낮은 점수는 나쁜 답의 증거가 아니다.**

## 2. 기준선 없이는 숫자를 읽을 수 없다

한국어 문장 둘은 서로 무관해도 조사와 어미를 공유한다. 유사도는 0에서 시작하지
않는다.

그래서 **우연 수준**을 함께 낸다. 기록된 답변들끼리의 유사도이며, 서로 다른 질문에
대한 답이므로 "무관한 두 답변이 이미 얼마나 닮았는가"를 말한다.

상한은 1.0(완전 일치)이다. 보고하는 값은 **우연에서 완전 일치 쪽으로 얼마나
움직였는가**다.

## 3. 결과

### 1차 (held-out 6쌍)

| profile | 우연 대비 위치 | 단어 겹침 | 생성 길이 |
| --- | ---: | ---: | ---: |
| `base` | 0.028 | 0.011 | 25.8단어 |
| `reference_broadcast` | 0.021 | 0.000 | 4.67단어 |

표본이 6쌍이라 해석할 수 없었다.

### 2차 (source-003 전체, held-out 20쌍)

쌍을 11개에서 **40개**로 늘렸다.

| profile | 우연 대비 위치 | 유사도 | 단어 겹침 | 생성 길이 |
| --- | ---: | ---: | ---: | ---: |
| `base` | 0.027 | 0.148 | 0.113 | 15.7단어 |
| `reference_broadcast` | **0.105** | 0.216 | 0.034 | **4.15단어** |
| 우연 수준 | 0 | 0.124 | — | — |
| Reference 실제 | 1.0 | — | — | **8.85단어** |

**`reference_broadcast`가 우연 대비 0.021에서 0.105로 올라갔다.** 표본이 커지자
우연 수준을 측정 가능하게 벗어났다. 다만 1.0과는 여전히 멀다.

`base`는 단어 겹침이 더 높지만(0.113 대 0.034) 우연 대비 위치는 낮다. 15.7단어를
쏟아내면 우연히 겹치는 단어가 늘어날 뿐이다. **단어 겹침만으로 판단하면 긴 답이
유리해진다.**

## 4. 예상 밖의 발견 — 길이가 맞지 않는다

1차에서는 생성 4.67단어, Reference 5.0단어로 **길이가 맞았다.** 2차에서는 생성
4.15단어, Reference **8.85단어**로 절반이다.

Reference의 답변 길이가 구간에 따라 다른 것이 아니다. **1차의 5.0단어가 특정 구간의
값이었고, source 전체로 보면 8.85단어다.**

말투 profile은 **단독 방송**에서 도출됐고 그 register의 평균 발화는 3.0단어였다.
`max_sentences: 1`, `max_words_per_sentence: 8`도 그 값에 맞춘 것이다.

**인터뷰에서 Reference는 그보다 길게 답한다.** 문서에 "방송 register와 1:1 대화
register가 다를 수 있다"고 적어둔 한계가 처음으로 숫자를 갖게 됐다.

| register | Reference 평균 발화 |
| --- | ---: |
| 단독 방송 | 3.0단어 |
| 인터뷰 답변 | 8.85단어 |

이는 말투 profile이 **어느 상황에서 관찰됐는지를 함께 기록해야 한다**는 뜻이며,
상황에 따라 다른 profile이 필요할 수 있다는 신호다.

## 5. 실행

```bash
docker compose -f compose.yaml -f compose.llm.yaml -f compose.gpu.yaml run --rm \
  -v "$REFERENCE_STORAGE_ROOT:/ref" dev \
  python experiments/content_holdout_eval.py \
  --pairs-path /ref/derived/transcripts/raw/pairs-<name>.json \
  --train-ratio 0.5
```
