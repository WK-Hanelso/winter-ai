# 대화 내용 held-out 평가

말투가 아니라 **무슨 말을 하는가**를 재는 절차와 첫 결과다.
`ADR-0004` D2가 대화 행동 학습 결정의 선행 조건으로 건 측정이다.

관련: [style-holdout-evaluation.md](style-holdout-evaluation.md),
[diarization.md](diarization.md).

---

## 1. 이 측정이 답하는 것과 답하지 않는 것

**답한다**: companion의 답이 Reference가 실제로 한 답과 얼마나 가까운가.

**답하지 않는다**: 그 답이 좋은가. 기록된 답은 질문마다 하나뿐이고 다른 답도 똑같이
적절할 수 있다. **낮은 점수는 나쁜 답의 증거가 아니다.**

## 2. 기준선 없이는 숫자를 읽을 수 없다

한국어 문장 둘은 서로 무관해도 조사와 어미를 공유한다. 유사도는 0에서 시작하지
않는다.

그래서 **우연 수준**을 함께 낸다. 기록된 답변들끼리의 유사도이며, 서로 다른 질문에
대한 답이므로 "무관한 두 답변이 이미 얼마나 닮았는가"를 말한다.

상한은 1.0(완전 일치)이다. 보고하는 값은 **우연에서 완전 일치 쪽으로 얼마나
움직였는가**다.

## 3. 결과 (source-003 20:00~25:00, 쌍 11개 중 held-out 6개)

| profile | Reference와 유사도 | 단어 겹침 | 우연 대비 위치 | 생성 길이 |
| --- | ---: | ---: | ---: | ---: |
| `base` | 0.084 | 0.011 | 0.028 | 25.8단어 |
| `reference_broadcast` | 0.077 | 0.000 | 0.021 | 4.67단어 |
| 우연 수준 | 0.057 | — | 0 | — |
| Reference 실제 | — | — | 1.0 | 5.0단어 |

### 판정: 내용은 재현되지 않는다

두 profile 모두 **우연 수준을 거의 벗어나지 못했다**(0.02~0.03). 단어 겹침은
사실상 0이다. companion의 답은 Reference가 실제로 한 답과 공유하는 것이 거의 없다.

### 그러나 길이는 맞았다

`reference_broadcast`의 답변 길이가 **4.67단어로 Reference의 5.0단어와 거의 같다.**
`base`는 25.8단어로 5배다.

**말투는 맞고 내용은 맞지 않는다.** `ADR-0002`가 요구한 "구성요소별 실패 분리"가
숫자로 나타난 형태다.

## 4. 이 결과로 학습을 결정할 수 없다

내용이 우연 수준이라는 것은 사실이지만, **측정 설정 자체에 심각한 제약이 있다.**

- **held-out이 6쌍이다.** 기준선 추정에도 부족한 표본이다
- **질문이 잘려 있다.** 화자 미배정 구간이 턴을 끊어 "곡을 사실" 같은 문장 조각이
  질문으로 들어간다. 사람도 답할 수 없는 입력이다
- **맥락이 없다.** 인터뷰 중간의 한 질문만 떼어 주었다. Reference는 앞의 30분을
  알고 답했다
- 기록된 답은 하나뿐이며 다른 적절한 답이 낮은 점수를 받는다

따라서 이 결과는 **"대화 학습이 필요하다"의 근거가 아니다.** 측정을 먼저 개선해야
한다는 뜻이다.

## 5. 실행

```bash
docker compose -f compose.yaml -f compose.llm.yaml -f compose.gpu.yaml run --rm \
  -v "$REFERENCE_STORAGE_ROOT:/ref" dev \
  python experiments/content_holdout_eval.py \
  --pairs-path /ref/derived/transcripts/raw/pairs-<name>.json \
  --train-ratio 0.5
```

## 6. 다음에 필요한 것

측정을 쓸 만하게 만들려면 순서대로,

1. **쌍 수 늘리기** — 나머지 구간과 source로 확장. 현재 5분당 11쌍
2. **질문 잘림 해소** — 미배정 구간 처리 개선
3. **맥락 제공** — 앞선 대화를 함께 주고 답하게 하기

세 가지가 되기 전의 점수는 참고값이며 결정 근거가 아니다.
