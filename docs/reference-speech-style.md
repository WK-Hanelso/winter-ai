# Reference 말투 특성 추출

단독 화자 전사에서 말투를 통계로 측정하는 절차와 결과다. 손으로 쓴
`VerbalStylePlanner` 정책을 Reference 근거로 대체하기 위한 입력이다.

관련: [ADR-0002](adr/0002-coupled-human-reference-baseline.md) 결정 5,
[ADR-0003](adr/0003-reference-transcription-strategy.md),
[roadmap.md](roadmap.md) Order 8.

---

## 1. 왜 지금 가능한가

`ADR-0002` 결정 5는 관계·맥락 모델보다 **prompt/few-shot baseline이 먼저**라고 정했다.
roadmap Order 8도 같다.

말투 baseline은 단독 화자 source만으로 만들 수 있고, 화자 분리를 기다릴 필요가 없다.
대화 상대에 따른 말투 변화는 관계 정보 단계의 문제다.

## 2. 입력 선택 — whisper를 1차로 쓴다

| 근거 | 내용 |
| --- | --- |
| 재현성 | 고정 image와 checkpoint로 언제든 다시 만든다. 자동 caption은 서비스 산출물이라 변경·삭제를 통제할 수 없다 |
| source 간 일관성 | 자동 caption은 생성 시점에 따라 성격이 크게 다르다. 실측에서 한 source는 문장부호 0.00/1000자, 다른 source는 60.24/1000자였다 |
| 커버리지 | 시간 커버리지가 근소하게 높다 (0.676/0.726 대 0.658/0.703) |

자동 caption은 **대조용**으로 함께 측정한다. 두 전사에 모두 나타나는 특성만
설계 근거로 쓰고, 한쪽에만 있는 것은 도구의 산물로 취급한다.

> 최초에는 자동 caption을 1차로 쓰려 했다. 근거가 "자동 caption은 문장부호를 붙이지
> 않아 구어에 가깝다"였는데, 그것은 구형 ASR로 생성된 source에만 해당했다. 대상
> source에서는 자동 caption의 문장부호가 whisper보다 2~5배 많았다.
> [ADR-0003 §E3](adr/0003-reference-transcription-strategy.md)가 경고한 함정을
> 그대로 밟을 뻔했다.

## 3. 측정 항목

| 항목 | 방법 |
| --- | --- |
| 종결 어미 | 표층 패턴으로 격식체 / 비격식 존댓말 / 반말 분류. 긴 형태 우선 (`습니다`가 `다`보다 먼저) |
| 발화 길이 | 문장부호가 있으면 문장 단위, 없으면 cue 단위. 단어 수 평균과 중앙값 |
| 필러 | 한글 단어 경계로 완전 일치만 계수 |
| 즉시 반복 | 한 발화 안에서 연속으로 같은 단어. 발화 경계를 넘는 반복은 전사 이음매일 가능성이 높아 제외 |
| 고빈도 어휘 | 필러와 한 글자 단어를 제외한 상위 목록 |

## 4. 실행

```bash
PYTHONPATH=src python3 experiments/reference_speech_style.py \
  --source-id <source-id> \
  --transcript <외장>/derived/audio/stt-pilot/<source>-0-<duration>.vtt \
  --secondary-transcript <외장>/raw/subtitles/<candidate>/<source>.ko-orig.vtt \
  --report-path <외장>/reports/<name>.json
```

## 5. 측정 결과 (2026-08-09, source-004, 35분 전체)

| 항목 | whisper | 자동 caption |
| --- | ---: | ---: |
| 발화 수 | 441 | 491 |
| 단어 수 | 1,324 | 1,319 |
| 평균 발화 길이 | 3.00 단어 | 2.69 단어 |
| 중앙값 | 3.0 | 2.0 |
| 격식체 종결 | 1 | 1 |
| 비격식 존댓말 종결 | 44 | 47 |
| 반말 종결 | 99 | 108 |
| 미분류 | 297 | 335 |
| **존댓말 비율** | **0.312** | **0.308** |
| 필러 | 35회 (2.64/100단어) | 50회 (3.79/100단어) |
| 즉시 반복 | 5회 (0.38/100단어) | 9회 (0.68/100단어) |

대조: 단어수비 **1.004**, 발화길이비 1.118, 필러율비 0.697, 존댓말비율차 **0.005**.

### 두 전사가 합의한 것 — 설계 근거로 쓸 수 있다

1. **반말이 우세하다.** 분류된 종결 어미 중 존댓말은 약 31%다. 두 전사가 0.005 차이로
   일치한다.
2. **발화가 짧다.** 평균 3단어 안팎, 중앙값 2~3단어. 길게 이어가지 않는다.
3. **격식체를 거의 쓰지 않는다.** `습니다` 계열이 각각 1회뿐이다.
4. **공통 고빈도 어휘**: `우리`, `근데`, `없어`, `나는`, `내가`, `지금`, `오늘`,
   `있어`, `같아`, `내일`, `수도`. 접속사 `근데`가 양쪽 상위에 있다.
5. **상위 필러**: `뭔가`, `그러니까`, `진짜`, `약간`. `뭔가`가 양쪽 1위다.

단어 수가 1,324 대 1,319로 거의 같다는 점이 특히 중요하다. 독립적인 두 ASR이 같은
분량을 산출했다는 뜻이며, 어느 쪽도 크게 빠뜨리지 않았다는 근거다.

### 대조가 잡아낸 오염

자동 caption의 최상위 어휘가 **`음악`(41회)**인데 whisper에는 나타나지 않는다.
발화가 아니라 배경 음악 구간의 caption 산물로 판단한다. 자동 caption만 썼다면 이
단어가 말투 프로파일의 1위 어휘가 됐을 것이다.

고유명사도 어긋난다. whisper는 `바봉이`(13) / `바봉`(8)으로, 자동 caption은
`바이`(8)로 인식했다. 어느 쪽이 맞는지는 정답이 없어 판정할 수 없다.

**대조 전사를 함께 측정한 것이 실제로 값을 했다.**

## 6. 알려진 한계

- **미분류 발화가 67%다.** 종결 어미 분류는 분류된 33%에 대해서만 유효하다. 표층
  패턴만 쓰기 때문이며 명사구로 끝나는 단편이 많다. 존댓말 비율 0.31은 분류된 것
  중의 비율이다
- **방송 말투는 1:1 대화 말투와 다르다.** 위버스 라이브는 다수 청자를 향한 발화다.
  존댓말 비율, 호칭, 발화 길이가 대화에서 달라질 수 있다. 이 결과는 **"방송 register에서
  관찰된 말투"**로만 유효하다
- held-out 평가도 같은 register 안에서만 가능하다
- 필러 계수는 두 도구 간 일관된 우열이 없다 (비율 0.697). 절대값이 아니라 순위를 쓴다
- 형태소 분석기를 쓰지 않는다. 도입하면 미분류 비율을 크게 줄일 수 있다
- source 하나, 35분만 측정했다

## 7. 다음 단계에 넘기는 것

`VerbalStylePlanner` 교체 시 근거로 쓸 수 있는 것:

- 기본 register는 반말. 존댓말은 소수
- 짧은 발화. 문장을 길게 잇지 않는다
- `근데`로 화제를 전환하는 빈도가 높다
- 머뭇거림은 `뭔가`, `약간`, `진짜`, `그러니까` 순

교체 자체는 런타임 동작을 바꾸므로 별도 issue로 설계한다.
