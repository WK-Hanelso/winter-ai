# 응답 음성 클립

Reference의 각 응답에 대해 텍스트와 함께 **그 발화의 오디오**를 남긴다.

관련: [diarization.md](diarization.md),
[content-holdout-evaluation.md](content-holdout-evaluation.md).

---

## 1. 왜 텍스트와 함께 두는가

`ADR-0002`는 Human Reference를 `context + script + voice + delivery`가 정렬된 하나의
관찰 단위로 취급한다. 텍스트만 남기면 그 정렬이 끊긴다.

응답의 시간 구간은 **오디오와 텍스트를 잇는 유일한 연결**이다. 나중에 텍스트만 보고
어느 소리가 그 발화였는지 되찾을 방법이 없다.

Order 7(Reference Voice baseline)은 "같은 문장을 원본과 합성으로 비교"하는 단계다.
그때 필요한 것이 정확히 이 쌍이다.

## 2. 구현

표준 라이브러리 `wave`만 쓴다. 입력이 이미 16 kHz mono PCM이라 디코더가 필요 없고,
이 단계가 무거운 image로 옮겨가지 않는다.

응답 턴의 `(시작, 끝)`으로 프레임을 잘라 `derived/audio/responses/`에 mode 0600으로
쓴다. 같은 이름이 있으면 덮어쓰지 않는다.

## 3. 결과 (source-003 전체)

| 항목 | 값 |
| --- | ---: |
| 응답 클립 | 42개 |
| 총 크기 | 6.7 MiB |

쌍 데이터 42개와 1:1로 대응한다.

## 4. 알려진 한계

- **겹쳐 말한 구간은 응답에서 제외되지 않는다.** 화자 분리가 미배정으로 표시한 부분은
  턴 밖이지만, 턴 안에서 상대가 짧게 겹쳤다면 그 소리가 클립에 남는다
- 클립 길이는 전사 타이밍에 의존한다. whisper의 단어 경계가 정확하지 않으면 앞뒤가
  잘리거나 남는다
- 음질은 원본 스트림 그대로다. 잡음 제거나 정규화를 하지 않았다
